## 日本語

このリポジトリは **GitHub Copilot Quest Lv.3 — COBOL Modernization to Azure** の
ワークショップ用教材です。以下の順で解決を試みてください。

### 1. 🤖 まず GitHub Copilot に聞く

この Quest の主役は **GitHub Copilot** です。セットアップやコードの疑問は、
まず Copilot に問いかけるのが近道であり、それ自体が学びになります。

- 「このリポジトリは何をするアプリ？」「エントリポイントはどこ？」
- 「この `Makefile` は何をする？」「このテストは何を保証している？」

### 2. 📖 README とドキュメントを確認する

- 環境構築・ビルド・実行手順: [README.md](./README.md)
- 貢献の方法: [CONTRIBUTING.md](./CONTRIBUTING.md)
- 行動規範: [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)

### 3. 🔎 既存の Issue を検索する

同じ問題がすでに報告・解決されているかもしれません。
[Issues](https://github.com/shinyay/legacy-modernization-ws-cobol-260630/issues)
を検索してみてください。

### 4. 🐛 新しい Issue を立てる

解決しない場合は、新しい Issue を作成してください。以下を含めると助かります。

- 期待した挙動と実際の挙動
- 再現手順（実行したコマンド、`make` ターゲットなど）
- 環境（Dev Container / Codespaces / ローカル、OS など）
- 関連するログやエラーメッセージ

### ⏱️ 対応について

ワークショップ教材のため、サポートはメンテナ
**[@shinyay](https://github.com/shinyay)** による **ベストエフォート** です。
セキュリティに関わる報告は [SECURITY.md](./SECURITY.md) を参照してください。

## English

This repository is workshop material for **GitHub Copilot Quest Lv.3 — COBOL
Modernization to Azure**. Please try the following steps in order.

### 1. 🤖 Ask GitHub Copilot first

**GitHub Copilot** is the star of this Quest. For questions about setup or code,
asking Copilot first is the fastest route — and it is itself part of the
learning.

- "What does this repository do?" "Where is the entry point?"
- "What does this `Makefile` do?" "What does this test guarantee?"

### 2. 📖 Check the README and docs

- Setup, build, and run instructions: [README.md](./README.md)
- How to contribute: [CONTRIBUTING.md](./CONTRIBUTING.md)
- Code of Conduct: [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)

### 3. 🔎 Search existing Issues

The same problem may already have been reported or resolved. Try searching the
[Issues](https://github.com/shinyay/legacy-modernization-ws-cobol-260630/issues).

### 4. 🐛 Open a new Issue

If that does not resolve it, please open a new Issue. Including the following
helps:

- The expected behavior and the actual behavior
- Reproduction steps (commands you ran, `make` targets, etc.)
- Your environment (Dev Container / Codespaces / local, OS, etc.)
- Relevant logs or error messages

### ⏱️ About support

As this is workshop material, support is **best-effort** by the maintainer
**[@shinyay](https://github.com/shinyay)**. For security-related reports, see
[SECURITY.md](./SECURITY.md).
